## 🪐 Key Features

### 1. Interactive Floating Tech Universe (Zero-G Physics Sandbox)
* **36+ Tech Skills Floating**: UX Design, Design Tools, Frontend, Tools & Platforms, CS Fundamentals, and Soft Skills.
* **Physics & Interactivity**:
  * **Grab & Fling**: Click, drag, and toss pills across the screen with real momentum and bounce collisions.
  * **Zero-G Drift**: Gentle cosmic floating with subtle sine-wave drift.
  * **Ball-Pit Gravity**: Toggles real-world downward gravity where pills bounce off the bottom.
  * **Disperse / Repel**: Explosive shockwave flings all pills outward.
  * **Orbit Vortex**: Pulls all floating pills into a swirling central gravitational vortex.
  * **Category Filter**: Filter by `UX Design`, `Design Tools`, `Frontend`, `Tools & Platforms`, `CS Core`, and `Soft Skills`.
  * **Hover Tooltips**: Contextual cards highlighting where Manali applied each tool.

### 2. Rich Aesthetics & Micro-Animations
* **3D Holographic Hero Stage**: Designer avatar with 3 orbiting dashed satellite rings carrying continuously bobbing tech pills (Figma, React.js, JavaScript, Python, UX Research, LeetCode).
* **3D Card Tilt with Specular Glare**: Interactive cards tilt in 3D perspective based on mouse position.
* **Ambient Constellation Background**: Subtle starfield with constellation lines that connect toward the user's cursor.
* **Custom Glowing Cursor**: Magnetic cursor with an expanding glowing aura on interactive elements.
* **Synthesized Audio Effects (Web Audio API)**: Soft clicks, swooshes, and chimes on button presses and pill throws (with mute toggle).
* **Theme Accent Switcher**: Instant switching between **Electric Violet**, **Cyber Cyan**, **Neon Rose**, and **Emerald Mint**.
* **Dynamic Typing Subtitle**: Cycling through Manali's core roles.
* **Scroll-Triggered Number Counters**: Animated counters for 50+ Screens, 100+ LeetCode Solved, 8.4/10 CGPA, and 2+ Certifications.
